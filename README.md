
# WiDS Global Datathon 2026 – Europe Team

## Project Title
**Predicting Time-to-Threat for Evacuation Zones Using Survival Analysis**

---


## Overview
This repository contains our work for the **WiDS Global Datathon 2026**, where we developed predictive models to estimate **time-to-threat in evacuation zones** using survival analysis techniques.
Our objective is to provide meaningful insights into how quickly hazardous conditions may evolve, supporting better **risk assessment and decision-making**.


## Repository Structure
- `europeteam-rst-version.1.ipynb` →  **Final competition notebook**
- Other notebooks / scripts → experimentation, feature engineering, and model exploration

The **official version submitted on Kaggle** for the competition corresponds to:
